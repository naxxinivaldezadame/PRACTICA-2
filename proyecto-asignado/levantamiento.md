Reporte de Levantamiento - Práctica 2. 
1. 
Introducción y Requisitos
En este reporte se documenta el proceso técnico de clonación, despliegue mediante contenedores Docker y verificación de la base de datos del proyecto asignado de obras públicas municipales. Se requirió contar con Git, la aplicación de Docker Desktop activa y una terminal compatible. 
2.
Bitácora de Pasos Ejecutados: Primero, se descargó el código fuente del proyecto utilizando la terminal con el comando git clone https://github.com/naxxinivaldezadame/PublicMunicipalWorks_DWH y posteriormente se accedió al directorio con cd PublicMunicipalWorks_DWH. Segundo, con Docker Desktop funcionando en el equipo, se ejecutó el archivo de configuración para levantar la infraestructura de la API y la base de datos mediante el comando docker compose -f docker/compose.yml up -d --build. Tercero, se comprobó la disponibilidad y correcta ejecución del servicio web local ejecutando curl http://localhost:5000/api/health. 
3. Incidencias y Solución de Errores: Durante el proceso surgió un problema de conexión a PostgreSQL ya que al intentar ingresar al contenedor con el comando predeterminado docker exec -it obras-publicas-db-1 psql -U postgres, la terminal rechazó el acceso mostrando el error psql: error: connection to server on socket ... FATAL: role "postgres" does not exist. Como solución aplicada, se identificó que la instancia utiliza un usuario personalizado, por lo que se inspeccionaron las variables de entorno del contenedor en ejecución con el comando docker exec obras-publicas-db-1 env | findstr POSTGRES, lo cual arrojó que el usuario correcto es obras y la base de datos es obras_publicas, logrando la conexión exitosa mediante docker exec -it obras-publicas-db-1 psql -U obras -d obras_publicas. 
4. Ejecución de Consultas y Evidencias: Dentro de la consola de la base de datos ya conectada, se realizó una consulta de verificación sobre una de las tablas del modelo dimensional ejecutando SELECT * FROM constructora LIMIT 5;. Las capturas de pantalla que documentan el arranque en Docker, la respuesta de la API y los resultados de la consulta SQL se encuentran resguardadas en la carpeta evidencias de esta entrega.
